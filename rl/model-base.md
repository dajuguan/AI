## Model-Based RL 概念辨析

### 1. 为什么假设 reward 与转移概率条件独立?

MDP 最一般的模型(Sutton & Barto 的四参数形式)是一个**联合分布** $p(s', r \mid s, a)$,同时刻画「下一个状态」和「即时奖励」。所谓条件独立假设,就是把它分解成:

$$
p(s', r \mid s, a) = \underbrace{p(s' \mid s, a)}_{\text{转移模型}} \cdot \underbrace{p(r \mid s, a)}_{\text{奖励模型}}
$$

即**给定 $(s,a)$ 后,$r$ 和 $s'$ 互不相关**。注意这不是 MDP 的定义要求,只是 model-based 里常做的简化。

**为什么可以这么假设(根本原因)**

价值函数只关心**期望**,而期望对奖励是**线性**的:

$$
Q(s,a) = \mathbb{E}[\,r \mid s,a\,] + \gamma\, \mathbb{E}_{s'}\!\big[V(s')\big]
$$

关键在这一步的拆分:

$$
\mathbb{E}\big[\,r + \gamma V(s') \mid s,a\,\big] = \mathbb{E}[r\mid s,a] + \gamma\,\mathbb{E}[V(s')\mid s,a]
$$

由期望的线性性,**无论 $r$ 和 $s'$ 的联合分布如何相关,这个等式都成立**。于是决定 $V,Q$ 的只有两样东西:**期望奖励** $\bar r(s,a)=\mathbb{E}[r\mid s,a]$ 和 **转移边缘** $p(s'\mid s,a)$;二者之间的相关结构(协方差、耦合)完全不进入 Bellman 方程。所以对「最大化期望回报」这个标准目标,条件独立假设是 **without loss of generality**——真实世界里 $r$ 和 $s'$ 就算强相关,最优策略也不变。

**为什么值得这么假设(工程收益)**

- **解耦学习**:分别训练转移模型和奖励模型,而不必估计 $\mathcal{S}\times\mathbb{R}$ 乘积空间上的联合密度(后者要额外刻画相关性,样本效率和建模难度都高得多)。
- **奖励常本就只依赖 $(s,a)$**:很多任务里 reward 是人为设计的确定性函数 $r(s,a)$,天然与 $s'$ 独立。
- **规划/rollout 更简单**:Dyna、MCTS、MPC 里先采样 $s'$、再单独给出 $r$,两个模块可独立替换和调试。

**什么时候失效(边界)**

条件独立之所以"免费",前提是目标为**期望回报的线性泛函**。一旦目标涉及回报分布的**高阶矩**,相关性就不再无关:

- **风险敏感 RL**:优化方差、CVaR 等,回报方差依赖 $r$ 与后续 $V(s')$ 的协方差;
- **Distributional RL**:显式建模回报分布 $Z(s,a)$,$(r,s')$ 的联合结构会影响分布形状;
- 奖励确实依赖 $s'$ 且带随机性时,严格来说 $r$ 与 $s'$ 相关(但只要还是期望目标,用 $\bar r(s,a)=\mathbb{E}_{s'}[r(s,a,s')]$ 归约后依然不影响价值)。

> 一句话:不是因为现实中二者真的独立,而是因为在期望回报意义下它们的相关性对价值函数**不可见**,于是假设独立既零代价、又能把联合模型拆成两个易学的子模型。

### 2. 为什么用模型求 value/policy 叫 planning,而不是 learning?

划分标准只有一条——**这次价值/策略更新用的样本从哪来:真实环境(learning) 还是模型(planning)。**

- **Learning(学习)**:从**真实经验**(与环境交互采样得到的 $s,a,r,s'$)中改进 value/policy。
- **Planning(规划)**:S&B 原文 *"any computational process that takes a **model** as input and produces or improves a policy"*——以**模型**为输入、通过计算产出或改进策略。

一旦有了模型 $p(s'\mid s,a)$、$r(s,a)$,求 value/policy 就变成纯粹的**计算问题**:可以在"脑子里"对模型做前瞻推演,而不必真的去环境试错。这正是 AI 里 planning 的本义——**用世界模型前瞻推演来决定行动**(Value/Policy Iteration、MCTS、MPC 都是 planning);而 Q-learning 直接从真实 transition 里 bootstrap、靠试错,是 learning。

**更深一层:二者是同一件事的两种数据源**

S&B 强调 planning 和 learning 的 **unified view**:本质都是**通过 backup 更新价值函数**,唯一区别是 backup 用的样本从哪来。**Dyna** 就是明证——它把同一套 Q-learning 更新,既用在真实经验上(learning),又用在模型模拟经验上(planning),两者无缝混用。

### 3. planning vs learning ≠ 多步 vs 单步

一个常见混淆:以为 planning 就是"能模拟很多步的数据",learning 只能"根据单次数据学"。**错。分界是"数据从哪来",和"步数"是正交的两条轴。**

| | 单步 | 多步 |
|---|---|---|
| **learning(真实经验)** | Q-learning | $n$-step TD, MC, TD(λ) |
| **planning(模型经验)** | Dyna-Q 的单步 backup | MCTS、MPC 的多步 rollout |

四个格子都填得满:

- **learning 也能多步**:$n$-step TD、Monte Carlo(用整条 episode 的真实回报)、TD(λ) 全是 learning 却用多步真实数据;
- **planning 也能单步**:Dyna-Q 从模型采样**一条** $(s,a)\to(r,s')$、做**一次单步** backup,仍是 planning。

"能模拟大量数据 / 深度前瞻"其实是**手里有模型带来的优势**,不是 planning 的定义:

- 想模拟多少数据就模拟多少(真实采样贵,模型采样几乎免费);
- 向前看很多步做前瞻搜索(MCTS);
- **重置到任意状态** $s$ 开始 rollout(真实环境往往做不到);
- 反复"回放"同一状态。

但哪怕你用模型只生成一步、只更新一次,它照样是 planning。判定标准始终只有一条:**样本来自真实环境还是模型。**

### 4. model-based + model-free 相比纯 model-free 的优势

**一句话主线**:模型显式建模了「世界怎么运转」这份**任务无关、可复用**的额外信息(动力学 $p(s'\mid s,a)$、奖励 $r$)。model-free 的 $Q/\pi$ 把这份知识**隐式地、和特定任务纠缠**地压进了数值里。所以一旦"环境变了"或"目标换了",拥有显式模型的一方有**天然优势**。

**优势不在"终点",而在"到达终点要花多少真实交互"**

数据无限的理论极限下,model-free 也收敛到最优,**两者终点相同**。所以结合的价值**不在渐近最优性,而在瞬态**:用少得多的**真实环境交互**达到同样的最优策略。关键是区分两种成本:

| 资源 | 特点 |
|---|---|
| **真实环境交互**(real experience) | 贵、稀缺、慢、可能有风险(机器人磨损、真金白银、看病、安全) |
| **计算 / 模型内模拟**(planning) | 便宜、快、可无限重复 |

Dyna 的本质就是**拿便宜的计算去换昂贵的真实交互**。"假设数据足够"这个前提在现实里往往根本不成立——真实样本才是瓶颈,所以 sample efficiency 就是全部意义。

**Dyna-Q 迷宫例子(David Silver / S&B)想说明什么**

就是**「达到最优所需的真实 episode 数」大幅减少**,而非终点更好。那张图三个要点:横轴是 episode(真实经验)不是计算量;三条线最终都压到 14 步(最优)——印证 model-free 也能到最优;区别只在收敛速度:0 planning(纯 Q-learning)要 ~25 episode,50 planning 只需 **2~3 个 episode**。

*为什么模型能省真实交互*:纯 Q-learning 每走一步真实 transition **只更新一个 $(s,a)$** 就扔掉;reward 只在终点 G 出现,价值要靠**反复真实穿越迷宫**才能一格格传回起点。Dyna-Q 则把 transition 存进模型,每步真实经验后**重放 $n$ 次已记住的 transition 做额外 backup**,在**一个 episode 内**就把奖励信息在状态空间里传播开。在确定性迷宫里,模型就是"经验缓存",Dyna-Q ≈ **experience replay**,增益本质是**信用分配的计算加速**。

**三个"效果上"能拉开差距的现实场景**

**① 规划性探索**:把"探索欲望"编码成模型内的奖励加成,让 planning 规划出**一整条通往未知区域的路径**,而非靠随机动作瞎撞。

- **Dyna-Q+**:对"已 $\tau$ 步没试过"的 $(s,a)$,在模型内部模拟时把奖励改成 $r + \kappa\sqrt{\tau}$。这份吸引力经 Bellman backup **反向传播**,planning 直接算出"专门绕过去看看"的策略。
- 对比 ε-greedy 的**局部随机扰动**:要到达十几格外的未知角落,靠连续随机走对,概率随距离**指数衰减**;planning 能做**有方向的深度探索**。
- **R-max / 乐观初始化**:把未知 $(s,a)$ 在模型里假设成通往"奖励最大的天堂",planning 会**系统性地**驱赶 agent 摸清所有未知状态(可给 PAC 保证)。纯 model-free 难做这种全局有计划的探索。

**② 模型可复用 / 迁移**:动力学 $p(s'\mid s,a)$ **与任务无关**,而 $Q(s,a)$ 把 dynamics 和 reward **焊死在一起**。目标一变,$Q$ 直接作废(仍指向旧目标),须重新采样;而模型不变,换 reward 重新 planning 即可,**零新增真实交互**。

- **迷宫换终点**:布局(模型)没变,对新 reward 重跑 value iteration → 瞬间得新最优策略;model-free 旧 Q 全指向旧终点,须从头重新探索。
- **机器人手臂**:动力学模型学一次,"够到 A""够到 B""画圆"等一堆任务**共用同一模型**做 MPC——这是 model-based 在机器人里最大卖点之一。
- 边界:迁移只在动力学确实共享、且新目标经过的状态模型学准了时成立。

**③ 应对环境变化**:变化通常是**局部**的(某路被封、某处开捷径)。有模型时,**少数几次**真实观测就能更新对应 transition,再靠 planning 把影响**全局传播**、快速重规划;model-free 须**反复真实重走**变化处很多次才能覆盖旧 Q,很慢。

- **Blocking maze(路被封)**:左路封死、右边新开。Dyna-Q 撞几次新墙后更新模型,planning 很快重新绕路。
- **Shortcut maze(开捷径)**:普通 Dyna-Q **可能永远发现不了捷径**——模型仍记"有墙"且当前策略够用、没理由再去。**Dyna-Q+** 的探索 bonus 会**周期性复查陈旧区域**从而发现捷径(把 ① 和 ③ 串起来了)。
- 现实:配送机器人某走廊施工封闭。model-based 观测到堵塞即更新地图、**立即重规划**;model-free 旧策略会一根筋撞老路,须真实失败很多次才"忘掉"旧路。

**但模型不是白拿的(代价)**

以上全以"模型正确"为前提。确定性迷宫里模型能学得完全准确,是纯赚。环境复杂、模型有偏(**model bias**)时,planning 会**把模型误差一并放大传播**。故现代做法(如 **MBPO**)通常**只用模型做短程 rollout**,避免长程误差累积。

> 总结:两种方法结合,买的不是"更好的终点",而是"用更少真实交互到达同一终点",并在**换目标 / 环境变化 / 主动探索**这些场景因**显式持有任务无关的环境知识**而占天然优势;代价是要承担模型误差的风险。真实数据廉价无限时它确实没优势——但现实里真实数据几乎从不廉价无限。

### 5. 案例:围棋为什么适合 simulation-based search(如 MCTS)

**简答(TL;DR)**:围棋**白送一个零误差的确定性模型**,而任何覆盖 $\approx10^{170}$ 局面的全局 policy/value 网络都只是**有损摊还、估不准,且误差在最尖锐、最决定胜负处被 argmax 放大**。于是与其信任全局网络的一次性输出,不如**每步用完美模型现场搜出局部精确解**——这同时买到**效率**(算力只花在当前可达子树)和**精度**(精确前瞻纠错)。展开成四点:

1. **完美模型零风险**:规则已知、确定、可观测,model bias 不存在,planning 免费可用;
2. **局部 vs 全局**:全局网络要"对所有棋盘都准"(难),MCTS 只需"对眼前这步准",用完就扔;
3. **搜索深度 = 纠错 + 逼近 $v^\star$**:把有偏的静态评估推向精确终局($v^\pi\to v^\star$),`min/max` 结构假设**最坏对手**、对未知/动态对手稳健;
4. **anytime**:多想即更强,而全局网络一次前向是定额、多想也不变。

下面是详细论证。围棋适合用 planning 式的 simulation-based search 而非纯 model-free,**主要不是"学得慢"(那是 §4 的 sample-efficiency 论点),而是效率 + 精度两方面**:

**原因一:围棋白送一个完美模型。** planning 的前提是"有模型"。围棋规则**已知、确定性、完全可观测**,落子后棋盘变成什么样百分百确定,不用学。于是 model-based 最大的软肋 **model bias 根本不存在**——模型就是规则本身,零成本、零误差。既然免费得到完美模拟器,不用它做前瞻就是浪费信息。

**原因二(核心):全局 $Q(s,a)$ 要"对所有棋盘都准",但你只需"对眼前这步准"。**

- **model-free 的 $Q(s,a)$ 是全局函数**:一组固定参数,试图对整个状态空间(围棋约 $10^{170}$ 个局面)**处处准**。它必须把"整盘棋的知识"压缩进参数、再泛化到眼前这个具体棋盘——这就是 Silver 说的"$Q$ 必须保存整盘信息",它是个**通用**函数。
- **MCTS 相反,是局部的、一次性的**:以**当前局面** $s_t$ 为根,只展开**从 $s_t$ 够得到**的后续局面,用完美模型现场 rollout 估值,**下完这步整棵树扔掉**。它的"价值函数"是**临时、局部**的,不需要处处准,只要"此时此地这几条线算得准"。
- **为什么局部更好**:给定当前局面,$10^{170}$ 里绝大多数局面**永远走不到**;全局 $Q$ 把算力平摊到全空间(含到不了的区域),搜索则把**全部算力砸在当前真正相关的路径**上。

> **导航类比**:全局 $Q$ = 背下"从世界任意路口去任意目的地下一步怎么拐"的巨表,要处处对、极难,大部分用不上;search = 手里有地图(模型),真要出门时**从当前位置**针对**当前目的地**现场规划一条路线,用完就扔,根本不需要那张全局表。

**原因三:search 不替代学习,而是在学习之上做局部纠偏。** 即便训练好一个强网络($V_\theta,p_\theta$),它仍是**全局近似**、必有误差。AlphaGo = **网络(全局近似,给搜索提供方向)+ MCTS(用完美模型实际走出这些线,当场纠正网络在此局面的错误)**。所以**同一个训练好的网络,加搜索比不加强很多**——这说明 search 的价值在**决策时刻的精确前瞻**,是纯 $Q/\pi$ 网络结构上给不了的。

**原因四:围棋局面"锋利"。** 一子之差死活/胜负可能翻转,价值函数极不平滑,平滑的函数近似器易在尖锐处判错;搜索**真的把这几步走出来**,能解出具体死活/劫争,不靠泛化猜。

#### 围棋的形式化定义

围棋是**有限、确定性、完全信息、两人零和**博弈,严格说是 **Markov game** 的特例(转移确定、无随机)。可把对手并入环境化归为 MDP。以 $n\times n$ 棋盘、$N=n^2$(标准 $n=19,N=361$):

$$
\mathcal{G} = \langle\, \mathcal{S},\ \mathcal{A},\ \mathcal{L},\ f,\ \mathcal{S}_{\text{term}},\ z,\ \gamma \,\rangle
$$

**状态 $\mathcal{S}$**:棋盘 $b\in\{\varnothing,\text{B},\text{W}\}^{N}$ 不足以满足马尔可夫性,完整状态还需带轮走方、劫争历史、连续 pass 计数:

$$
s = \big(\underbrace{b}_{\text{棋盘}},\ \underbrace{c}_{\text{该谁走}},\ \underbrace{h}_{\text{历史/劫争}},\ \underbrace{k}_{\text{连续 pass 数}}\big)
$$

其中 $h$:简单劫只需上一手禁着点,位置超级劫(positional superko)需记**所有历史局面**。合法局面数 $\approx 2.08\times10^{170}$。

**动作 $\mathcal{A}$ 与合法动作 $\mathcal{L}(s)$**:$\mathcal{A}=\{1,\dots,N\}\cup\{\text{pass}\}$。落子点 $p$ 对当前方合法 $\iff$ (1) $p$ 为空;(2) **非自杀**(落子提掉对方死子后,己方块气 $\ge 1$);(3) **不违反劫/超级劫**(落子后棋盘不重复历史局面)。块=同色四邻接连通分量,气=块相邻空点,气为 0 即被提。

**转移 $f$(确定性)**:$P(s'\mid s,a)=\delta(s'-f(s,a))$。$f$ 是可精确计算的规则算法:置子 → 提掉相邻且气为 0 的对方块 → 自杀检查 → 切换轮走方、更新劫争、pass 计数归零(pass 则棋盘不变、$k{+}1$、切换)。**正是"$P,R$ 都是已知可精确计算的函数",围棋才有零误差的完美模型,MCTS 得以直接施展。**

**终止**:$s\in\mathcal{S}_{\text{term}}\iff k=2$(连续两次 pass;实践另加投子/步数上限)。

**奖励 $z$(零和,仅终局)**:过程 $r_t=0$,终局 $r_T=z(s_T)$。中国规则(数子/area scoring):$\text{score}_c=\#\{\text{c 活子}\}+\#\{\text{仅被 c 围的空点}\}$,引入贴目 $\kappa$(补偿黑先,常取 $7.5$),黑方视角

$$
z=\operatorname{sign}\big(\text{score}_{\text{B}}-\text{score}_{\text{W}}-\kappa\big)\in\{+1,-1\}
$$

白方奖励为 $-z$。**折扣 $\gamma$**:有限时域,通常 $\gamma=1$。

**两处要点**:(1) 固定对手策略后并入环境即化归标准 MDP;AlphaGo 用**自博弈**,本质在解博弈的**极小极大值**。(2) 博弈的解是 minimax 值:

$$
V^\star(s) = \begin{cases}
z(s), & s\in\mathcal{S}_{\text{term}}\\
\max_{a\in\mathcal{L}(s)} V^\star(f(s,a)), & c=\text{B}\\
\min_{a\in\mathcal{L}(s)} V^\star(f(s,a)), & c=\text{W}
\end{cases}
$$

MCTS 即**从当前根 $s_t$ 出发、用完美模型 $f$ 采样估计这个 minimax 值**的近似算法——只在够得到的子树里现场估值、用完就扔,逼近的是**当前局面的局部精确值**,而非拟合覆盖 $10^{170}$ 局面的全局 $Q$。

#### §5.1 信息论视角:围棋的困难是计算性的,不是信息性的

把任何 MDP 的困难拆成两部分:

$$
\text{总难度} = \underbrace{\text{信息性不确定}}_{\text{对动力学 } P,R \text{ 的无知}} + \underbrace{\text{计算性难度}}_{\text{已知模型下算 } V^\star \text{ 有多贵}}
$$

围棋的特殊性在于 **第一项 $=0$**:规则完全已知、转移**精确确定**($P(s'\mid s,a)=\delta(s'-f(s,a))$,不是"几乎")。所以关于"世界怎么运转"**没有缺失的信息,只有缺失的计算**。

**用描述长度(Kolmogorov 复杂度)看两条路线。** 考虑两个对象:

$$
K(\text{规则}) \approx \text{几百行,极小} \qquad K(\text{最优价值表 } V^\star) \approx \text{天文级,极大}
$$

从极小的规则 + 当前局面,$V^\star(s)$ 对任意 $s$ **被唯一确定**(给定无限算力可精确算出)。即"正确应对"的**全部信息已无损地装在那份极小规则里**,一个 bit 不缺。

- **model-free**:想把 $K$ 极大的全局 $V^\star$ **有损压缩**进有限参数 $\theta$ 预存。但**参数容量(bits)$\ll K(V^\star)$** → 信息论上**必然丢信息 → 必然在某些状态判错**;这是信道容量不足,非"训练不够"。而围棋价值 landscape 极不平滑(一子定死活)、高频高熵难压缩,**压缩误差恰在最尖锐、最决定胜负处最大**。
- **model-based / search**:不预存答案,保留 $K$ 极小的**生成器(规则 $f$)**,需要时从当前局面**按需重算**——本质是**无损的"局部解压"**。

> 类比:model-free = 把"所有问题的答案"压进一本有限厚的书(必然有损,查到的可能错);search = 只存一段极短**生成程序**,谁提问就**现场跑一遍精确算出**这一题(每题精确、单题便宜)。围棋白送了这段零误差的短程序,放着不用非要去有损压缩天文级答案表,信息论上是**自找误差**。

**为什么精度在这里不是锦上添花。** 零和 + 尖锐,使 value 误差经 $\arg\max$ 被**硬阈值放大**:

$$
Q_\theta \text{ 有小误差} \Rightarrow \arg\max_a \text{ 选错一着} \Rightarrow \text{可能直接输棋}
$$

不是"值差一点、结果差一点",而是"值差一点、胜负翻盘"。search 用完美模型前瞻,能在**落子之前**走出并纠正这种局部误判——所以它提供的精度是**结构性的**,而非效率优化。

**唯一的不确定来自对手。** 转移精确确定,围棋里唯一的未知是**对手策略**——这正是用**自博弈 + minimax 搜索**的原因:动力学没有不确定性可估,需"应对"的只有对手,交给博弈树的 min 层 / self-play,不需要去学一个 $P$。

> 收紧:围棋的困难**纯粹是计算性的,信息性不确定为零**;model-free 却把它当**统计估计问题**——有损压缩 $K$ 极大的全局价值函数,注定有误差且在尖锐处经 $\arg\max$ 放大成败着;model-based 保留 $K$ 极小、零误差的规则生成器,**按需无损地局部重算**,既省(算力只花在相关子树)又准(不经有损压缩)。

#### §5.2 对照:QZero —— 用熵正则做 model-free 围棋(以及"无搜索"的代价)

**QZero**(NetEase AI Lab,*Mastering the Game of Go with Self-play Experience Replay*, 2026)是一个反向案例:**model-free、单 Q 网络、训练与评测都不用 MCTS**,专门挑战"value-based off-policy 因 Q-backup 的 **target bias** 而搞不定大规模环境"这一信念。它靠三件套:**Ignition(冷启动)+ 熵正则化 + Polyak averaging**。

**熵正则化(entropy regularization)的定义**:

- 策略熵 $H(\pi(\cdot\mid s)) = -\sum_a \pi(a\mid s)\log\pi(a\mid s)$(越均匀越大,越确定越小);
- 把熵作为内在奖励加进目标(Soft RL):$\pi^\star = \arg\max_\pi \mathbb{E}_\tau\big[\sum_t \gamma^t(r(s_t,a_t) + \gamma\alpha\,H(\pi(\cdot\mid s_{t+1})))\big]$;
- 于是策略变成对 Q 的 **softmax** 而非硬 argmax:$\pi_\phi(\cdot\mid s) = \mathrm{Softmax}(\tfrac{1}{\alpha}Q_\phi(s,\cdot))$;
- soft Bellman backup 多一项 $-\alpha\log\pi$:target 用"软价值" $V(s')=\mathbb E_\pi[Q]+\alpha H$;
- $\alpha$ 是温度(论文取 $0.081$);$\alpha=0$ 时退化回普通 RL、softmax 退化回硬 argmax。

**为什么"尖峰熵小、均匀熵大"(数学解释)**:熵 $H=-\sum_a \pi(a)\log\pi(a)$ 是每个动作的"意外程度" $-\log\pi(a)$(概率越小越意外)的**概率加权平均**。

- **极端①:确定性策略** —— 某动作 $\pi(a^\star)=1$、其余全 $0$。则 $H = -1\cdot\log 1 - \sum_{a\neq a^\star}0\cdot\log 0 = 0$(约定 $0\log 0=0$)。完全确定、毫无意外 → **熵 $=0$(最小)**。
- **极端②:均匀策略** —— $n$ 个动作各 $1/n$。则 $H = -\sum \tfrac{1}{n}\log\tfrac{1}{n} = \log n$ → **最大**,最不可预测。

所以峰越尖(概率越集中),加权平均的"意外"越小、$H$ 越小;越摊平 $H$ 越大。$H\in[0,\log n]$。

**"软策略(soft policy)"具体指什么**:指**不做非黑即白的 argmax,而按分数高低给每个动作分配一个概率**的策略——这里即对 Q 取带温度的 softmax:

$$
\pi_\phi(a\mid s) = \frac{\exp(Q_\phi(s,a)/\alpha)}{\sum_{a'}\exp(Q_\phi(s,a')/\alpha)}
$$

- **硬(hard)策略** $=\arg\max_a Q(s,a)$:概率 $1$ 全给最高的那个动作(熵 $=0$);
- **软(soft)策略** $=$ 上式:Q 高的动作概率大,但**次优动作也分到非零概率**(熵 $>0$),是 argmax 的"平滑化"。

温度 $\alpha$ 控制软硬:$\alpha\to0$ 无限逼近硬 argmax(熵 $\to0$),$\alpha$ 越大越接近均匀(熵越大)。"软"就是"**不硬性一刀切、留有余地**"。

**作用**:(1) 探索 + 训练稳定(平滑学习过程);(2) 提升训练效率与性能;(3) **统一 value/policy**——熵正则下 Soft Q-Learning $\equiv$ Soft Policy Gradient,故 QZero **只用一个 Q 网络**即可同时做评估与改进(策略 = softmax(Q/α)),省掉双网;(4) 平滑逼近 Nash 均衡。**代价**:引入 **entropy bias**(soft 最优 $\neq$ 真最优),原计划 $\alpha$ 退火 $\to 0$ 纠正(实际因未收敛而保持不变)。

> **方向**:熵正则化是**鼓励探索**——通过奖励高熵/惩罚过早确定,让策略保持柔软、敢试;$\alpha$ 是探索强度旋钮,通常随训练退火,把探索逐步收敛到利用。

**接回本节主线**:

- softmax $(Q/\alpha)$ 正是"**平滑版 argmax**"——既避免硬 $\arg\max$ 的脆性(§5.1 的误差放大),又用原则化的 Boltzmann 随机**替代 ε-greedy 的外部注入探索**;它是 GPI 里"策略改进算子"的**软版本**(AlphaGo 用 MCTS 当改进算子,QZero 用 softmax(Q/α),不搜索)。
- 但"**无搜索的代价**"与本节结论一致:QZero raw 网络(无 test-time 搜索)在线仅到 **5D 强业余、Elo ~2000–2100**,约等于 **AlphaGo(raw ~2200)**,但**远低于 AlphaGo Zero(raw 3055)、顶尖人类(3600–3800)、AlphaGo Zero+MCTS(5185)**。所以它证明的是"**model-free 单网络也能高效学到 AlphaGo 级**",**而非"搜索没用"**——不加 test-time 搜索仍停在业余段位,正印证了 §5:全局网络估不准、在关键处最致命,搜索(在线局部精确重算)才是跨到超人水平的关键。

### 6. 反面案例:LLM 的 post-training 为什么不需要 MCTS / 高精度

主流的偏好对齐类 post-training(RLHF / DPO / GRPO)**既不需要 MCTS,也不需要围棋那种精度——而且刻意压低精度**。把 §5 里"围棋需要搜索"的三个前提拿来对照,几乎全不成立:

| 前提 | 围棋 | LLM 偏好对齐 |
|---|---|---|
| 白送零误差模型 | ✅ 规则精确 | ❌ **reward 是学出来的近似**,没有可搜的精确模拟器 |
| 尖锐 / 对抗 | ✅ 一子定胜负、有对手 | ❌ 好答案很多、措辞小改不翻盘、**无对手反驳** |
| 要逼近精确最优 | ✅ minimax $v^\star$ | ❌ **反而刻意不追求**:要好分布,不是唯一最优 |

- **目标是"软"的**:偏好分数平滑、非零和,argmax 级误差不致命(不像围棋一步错就输)→ 不需要 minimax、不需要精确前瞻。
- **刻意不追求精确最优**:post-training 用 **KL 惩罚 + 熵正则**把策略**拴在基座附近**(即 §5.2 的"保持柔软")。过度优化 reward = **reward hacking**。这跟围棋搜索"硬逼近精确最优"**恰好相反**。

**关键连接:深搜有害,正是 §4 / MBPO 的老道理。** reward model 是个**有偏的模型**;像围棋那样**对它深度搜索**只会**放大它的偏差** → **reward hacking**。这与 §4 "model bias 会被 planning 放大,故 MBPO 只做短 rollout" 是**同一件事**:

$$
\text{围棋:模型精确 → 深搜安全} \qquad \text{RLHF:reward model 有偏 → 深搜=放大误差,故用 KL 短缰绳、不深搜}
$$

所以 RLHF 用**短 rollout + KL 约束**,不是搜不动,而是**搜了会坏事**。

**半例外:可验证推理任务。** 数学 / 代码 / 定理证明这类 **verifiable-reward** 任务更"围棋味":有近似 verifier 当 oracle、landscape 更尖锐(一步推理错 → 最终答案错 → reward 0)。所以 **test-time search / tree-of-thought / PRM(过程奖励)+ 搜索** 确有相关性。**但**实践(如 **DeepSeek-R1**)发现:纯 outcome-reward 的 RL(GRPO)**不用显式 MCTS 也很强**,模型自学**超长 CoT** 相当于把搜索**摊还**进 token 生成(隐式搜索),显式 MCTS 反而难 scale——又回到"摊还 vs 在线搜索"。

> 收束:围棋那种"必须精确前瞻"只在**精确/可验证模型 + 尖锐 + 对抗**三者齐备时才出现。LLM 对齐一个都不占(还主动用 KL/熵压低精度追求),故不用 MCTS;可验证推理任务占了一部分,但主流仍是**简单 RL + 模型自学长 CoT 的隐式搜索**,而非训练时显式 MCTS。
